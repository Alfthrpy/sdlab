# ADR 0001 — Tickets are stored as files in the repo

- **Status:** accepted
- **Date:** 2026-11-12

## Context

Development is done with cloud agents and a human owner as reviewer. Every session must know exactly what its task is. Cloud agents do not always have a valid GitHub API token, but they can always read the repo contents.

## Decision

Tickets are Markdown files with YAML frontmatter in `backlog/tickets/`. `backlog/BOARD.md` is generated by `scripts/board.py`. Ticket status changes are committed in the same PR as the work itself.

## Consequences

- Agents can work without API access, and ticket history is recorded in Git.
- Merge conflicts may occur in `BOARD.md`. Fix: regenerate it, never edit it by hand.
- No notifications or built-in GitHub kanban view. If needed, P1-004 adds a mirror to GitHub Projects with the files remaining the source of truth.
