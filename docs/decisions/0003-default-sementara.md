- **Status:** sementara. Diganti setelah P1-002 dan P1-003 selesai.

| Bahasa sumber | Inggris (sebagian besar sumber primer berbahasa Inggris) | — |

| Reviewer teknis manusia | Owner repo | P1-003 |
